# Analysis and Approach

The analysis used three primary datasets provided by Rockstar:
- **player_statistics.csv** — Player performance metrics and statistics
- **item_spend.csv** — In-game purchase transactions and spending data
- **player_activity.csv** — Player engagement and activity logs

**Analysis Components:**

1. **Data Integration and Preprocessing** — Merged multiple datasets on account_id, platform_id, and occur_date. Performed duplicate detection, missing value analysis, and date standardization.

2. **Spending Pattern Analysis** — Aggregated daily spending per player, analyzed item purchase frequency and distribution, and examined spending behavior across different player segments.

3. **Principal Component Analysis (PCA)** — Applied dimensionality reduction for pattern discovery, performed comparative analysis between missing and non-missing data subsets, and identified key features driving player behavior variance.

4. **Missing Data Investigation** — Systematic analysis of missing values in item_spend data, pattern identification in data completeness, and impact assessment on overall analysis.

**Technologies:** Python, pandas, numpy, matplotlib, seaborn, scikit-learn, Jupyter Notebook.
