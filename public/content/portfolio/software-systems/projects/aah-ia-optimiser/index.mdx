# Overview

This exploration compares **Gradient Descent** (first-order) and **Newton-Raphson** (second-order) optimizers across multiple benchmark functions (Rosenbrock, Rastrigin, Three-Hump Camel, Booth, Sphere) in varying dimensions, then tests them on a real **neural network training** task.

Key findings:
- **Gradient Descent** scales as O(n) per iteration, making it practical for high-dimensional AI training
- **Newton-Raphson** scales as O(n^3) due to Hessian inversion, becoming infeasible beyond ~50 dimensions
- Newton-Raphson converges in fewer iterations on smooth, low-dimensional functions but suffers catastrophic NaN failures in higher dimensions
- Mann-Whitney U tests confirm statistically significant runtime differences (p < 0.05)
- In real neural network training, Gradient Descent successfully trained the model while Newton-Raphson was computationally prohibitive
