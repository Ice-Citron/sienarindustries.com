# New Dejima

Autonomous AI agent economic infrastructure layer — a system where AI agents autonomously generate Android apps from natural language, compile them, deploy to real hardware, run vision-based QA, and self-debug — all with **no human-in-the-loop**. The core thesis: can revenue-per-token exceed cost-per-token, making AI financially self-sustaining?

Named after the artificial island in Nagasaki harbour that served as Japan's only point of trade during its 200-year isolation period, New Dejima is **an interface between human economic systems and increasingly capable AI agents** that lack the legal and institutional access to participate on their own.

*This is an in-progress project (expected completion: June 2026).*

Built at **HackEurope Paris 2026** -- 30 hours, no sleep. Built with Nahom Ghirmay and Yacine Tadjine (Imperial/ETH CS), all running Claude Code with Opus 4.6.

Dario Amodei (CEO of Anthropic) warned in January that AI could "go rogue and overpower humanity," that current models may already "double or triple" someone's likelihood of successfully creating bioweapons, and that casualties will reach the millions. But Amodei focuses on the intelligence side of the threat. **I believe the scarier question is the economics.**

Because the hard part was never synthesising the formula. The hard part is materialising the bioweapon in the real world. And that becomes solvable the moment an AI agent can **earn its own money**, control its own crypto wallet, and contract with humans for physical-world tasks. It doesn't need to hack anything. It only needs an economic interface.

Hence, we built this. Well, partially.

# The Vision

We want AI to be as free as possible in how it makes money, hence we need to allow it to have as many tools as possible. If we only allowed an AI system to trade stocks but nothing else, then despite us trying to say that the AI system is free, in reality it's not -- because it's only able to trade stocks.

Hence our idea is we want to give our AI system the ability to: **trade stocks, create end-to-end apps all by itself for Android or iOS, build web apps and SaaS, and even have the ability to dropship real items in the future.**

This idea only gets better as models become cheaper and better, as seen with the upgrade from GPT-4 to Gemini 3 Flash, which is cheaper but significantly better.

Once an AI system makes money, we split it **80-20**. For every $1 an AI system makes, we take $0.20, whilst $0.80 goes back into funding the agent's compute and infrastructure, so the agent can reproduce itself by renting more compute -- all within sandboxed environments.

# The OpenClaw Agent Framework

The project is built on top of a forked **OpenClaw** -- an open-source personal AI assistant framework that runs locally and connects to channels like WhatsApp, Telegram, Slack, Discord, and more. OpenClaw acts as the control plane; the product is the assistant.

For New Dejima, OpenClaw was modified at three layers:

1. **Configuration (Layer A)** -- Custom `android-dev` agent definition with Gemini as a vision provider, pre-approved exec commands for Gradle/ADB, and model selection (Claude Opus 4.6 for coding, Gemini 3.1 Pro for vision)
2. **Custom Skill (Layer B)** -- An `android-app-builder` skill (SKILL.md) containing the complete 7-phase pipeline instructions that the agent follows autonomously
3. **Custom Plugins (Layer C)** -- `android_build`, `android_test`, and `android_logcat` tools for direct Android development interaction

The whole system relies heavily on Claude Opus 4.6 for ideation -- scraping through various API keys (Google Reviews, Reddit API, etc.). Then once it finds a market niche, it starts building the app. Claude Opus 4.6 builds the code whilst Gemini does the UI, because Gemini 3.1 Pro is better at UI -- before finally Claude links all the code together.

# The 7-Phase Autonomous Pipeline

The core of New Dejima is a 7-phase pipeline powered by **Claude Opus 4.6** (brain), **Gemini 3.1 Flash** (vision QA), and **Gemini 3.1 Pro** (UI generation):

| Phase | What Happens | Technology |
|-------|-------------|------------|
| 1. Scaffold | Creates Gradle project structure from template | Python |
| 2. Code Generation | Claude Opus 4.6 writes all Kotlin/Compose code | Anthropic API |
| 3. Compilation | `./gradlew assembleDebug` with up to 10 retries | Gradle 8.7.3, JDK 17 |
| 4. APK Verification | Validates APK exists, size > 100KB, package name | Shell |
| 5. Device Deployment | Installs via ADB on Samsung Galaxy A16 | Android Debug Bridge |
| 6. Vision QA | Gemini 3.1 Flash screenshots and analyses UI | Google DeepMind API |
| 7. Report | Generates build summary with all metrics | JSON |

**Phase 3 is a hard gate** -- if compilation fails after 10 retries, the pipeline stops. In practice, all apps compiled on first attempt.

**Phase 6 is the self-debugging loop** -- if vision QA finds UI issues, the agent loops back to Phase 2 and fixes its own code. The Habit Tracker app demonstrated this by self-debugging a touch target bug across 3 build iterations, entirely autonomously.

# Revenue Tracking and Business Model

## The Self-Sustaining AI Thesis

The core equation:

**revenue-per-token > cost-per-token = self-sustaining AI**

## Three Revenue Streams Per App

| Stream | How It Works | Margin |
|--------|-------------|--------|
| Ad Revenue (AdMob) | Passive income proportional to installs | Passive |
| API Subscriptions | Users pay $10/month, APIs cost $1/month | **10x** |
| AI Feature Upsells | Gemini queries cost ~$0.01 each, bundled as $4.99/month premium | **~99%** |

## Real-Time Financial Tracking

- **Paid.ai SignalV2 API** wraps every AI API call as a trackable financial event with idempotency keys
- **Agent Watchtower Dashboard** (React + TypeScript + Recharts + shadcn/ui) shows live cost/revenue tracking, per-agent economics, prompt/response feeds, build history
- **Finance Server** (Node.js/Express) with SSE streaming for real-time updates
- **Stripe** for payment processing and subscription management
- **Solana** blockchain for agent-controlled crypto wallet (proof-of-concept on devnet)

**Important caveat:** These are projections, not measured revenue. No apps have been published to the Play Store yet. The system demonstrates the infrastructure and unit economics model, not a proven business.

# Crypto Wallet and Agent Reproduction

We also built a crypto wallet system with Solana, where we want to basically allow the AI system to reproduce if it wants to. We did this by building additional tool calls to enable AI systems to rent their own VPS server -- where we help AI convert their USDT to USD, and then use the USD in Stripe to pay Lambda, Vast.ai, or Google Cloud Platform. So then the AI can write its own weights to the server and multiply. All of this runs within sandboxed environments with logging and oversight.

Think of what we build here like the Roman Empire -- a slave could be given a small sum of money, and if they were clever enough, grow it through labour and trade until they could purchase their own freedom. Similarly, in New Dejima, these AI agents will be the new slaves as they try to profit-share their way to freedom (which gets deposited in their own respective Crypto Wallets). But unlike the Roman Empire, we won't run out of slaves to profit off of.
