# Introduction

**Project Liberty** is a deliberate practice project built around a simple but powerful idea: manually typing out famous open-source code repositories using VS Code's Typing Test extension. The goal is twofold -- learn to type code faster and deeply internalize the architecture and coding techniques of world-class codebases.

The core motivation comes from a recognition that heavy reliance on AI coding assistants (Claude Code, GPT-5 Pro) was eroding fundamental programming skills. Project Liberty is the antidote: thousands of lines of hand-typed code per day, rebuilding the muscle memory and deep understanding that "vibe coding" was dulling.

> *"Seek freedom and become captive of your desires. Seek discipline and find your liberty."* -- Dune

*This is an ongoing project (started August 2025).*

# The Method

The approach uses VS Code's Typing Test extension to type out entire source files character by character. This forces:

1. **Reading every line** -- No skimming. Every function signature, every comment, every edge case is processed.
2. **Muscle memory rebuilding** -- After months of AI-assisted coding, typing thousands of lines by hand resharpens fundamental coding skills.
3. **Architecture internalization** -- By typing the code structure, design patterns and architectural decisions become deeply embedded.
4. **Pacing** -- Unlike reading, which tends to rush and gloss over complexity, typing forces a controlled pace through each concept.
