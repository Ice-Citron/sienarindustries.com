# Introduction

Built at the **Perplexity Hackathon 2025** (October 2025), this project is a **Ground News-style** multi-source news analysis application. The app uses the Perplexity API to generate balanced news articles from multiple sources, providing users with diverse perspectives on current events, media bias analysis, and gamified news literacy quizzes.

# Features and Architecture

**Frontend (React + Tailwind CSS):**
- News feed with article cards showing coverage and diversity metrics
- Article detail pages with claims analysis and outlet coverage matrix
- Breaking news banner and market ticker
- Media bias diversity meter and coverage meter
- Search and command bar for quick navigation
- User authentication (Firebase), profiles, and leaderboard
- News literacy quizzes — daily quizzes, quiz runner, results, and history

**Backend (Node.js + Firebase Cloud Functions):**
- Perplexity API integration for generating balanced multi-source articles
- Article generation endpoint with topic and category parameters
- Firebase authentication and user management

**Key Components:**
- `ClaimsLens` — Breaks down factual claims within articles
- `OutletMatrix` — Shows which outlets cover each story and their political leaning
- `DiversityMeter` — Measures source diversity in coverage
- `CoverageMeter` — Tracks breadth of coverage across the political spectrum
