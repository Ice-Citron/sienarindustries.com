# Architecture

The system implements a complete training pipeline combining multiple components:

1. **vLLM with Qwen-14B** — The base language model generates security testing commands and strategies
2. **DVWA Challenges** — Damn Vulnerable Web Application provides realistic security testing environments
3. **Claude MCP Judge** — Evidence-based evaluation with hallucination detection serves as the reward signal
4. **GRPO Training** — Group Relative Policy Optimization (via OpenPipe ART) fine-tunes the model with vLLM sleep mode for efficient GPU memory usage

The pipeline uses **RLAIF (Reinforcement Learning from AI Feedback)** where Claude evaluates the security agent's actions, providing reward signals that guide the GRPO training loop. Training metrics are logged to Weights & Biases, with model checkpoints pushed to Hugging Face.
