# Introduction

**CareCompass** was built at the **Reply AIM Hackathon** (November 2025) as a team of four: Shi Hao Ng, Alex Goldman, Davin Wong, and Ryan Deng. The project is an AI-powered medical cost and reliability comparison platform, designed to help patients make informed decisions about medical procedures and medical tourism options.

# Features and Architecture

**Core Features:**
- **AI Consultant Chat** — Users can ask questions about medical procedure costs and receive AI-powered recommendations (e.g., "I need a hip replacement. What are my options?" or "Compare knee replacement costs between US and Thailand")
- **Global Hospital Map** — Mapbox-powered visualization of hospitals worldwide with reliability scores and pricing data
- **Cost Comparison** — Side-by-side comparison of US domestic vs. international medical tourism options
- **Reliability Scores** — Hospital quality ratings based on multiple factors

**Tech Stack:**
- **Frontend:** React + Vite + Mapbox GL JS
- **Backend:** Node.js + Express + OpenAI API
- **Data:** Mock dataset covering 18 hospitals across 8 countries (US, Thailand, Mexico, India, Turkey, Singapore, Germany, South Korea)

**Medical Procedures Covered:** Hip Replacement, Knee Replacement, Heart Surgery.

**Architecture:**
- Express backend with OpenAI API integration for the AI consultant chat
- React frontend with tabbed interface (AI Consultant / Browse Hospitals)
- Mapbox GL JS for interactive hospital map visualization
- JSON-based hospital data (extensible to real database connections)
